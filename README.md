# C++ Reference

Personal reference repo for C++ concepts — built while relearning. Each file has inline comments and examples.

## Structure

### 0. Basics
Core language fundamentals — variables, pointers, references, arrays, loops, conditionals, functions, structs, enums, memory.

### 1. Intermediate
Functions in depth, templates, header files, function pointers, null pointers, recursion, macros, variadic functions.

### 2. OOP
Classes, objects, getters/setters, constructors, destructors, `this` keyword, inheritance, polymorphism.

### 3. Modern CPP
Move semantics, lambdas, STL vector, smart pointers (unique, shared, weak).

### 4. File Handling
Creating, renaming, deleting files. Reading and writing modes.

### 5. CPP STL

| Subfolder | Topics |
|---|---|
| 0. Overview | STL vs Standard Library, components (containers, iterators, algorithms, functors) |
| 1. Containers | pair, vector, list, deque, stack, queue, priority_queue, set, multiset, map, multimap, unordered variants |
| 2. Algorithms | sort, binary search, count, find, accumulate, partition, permutation, max/min/reverse |
| 3. Functors & Comparators | functors, custom comparators |
